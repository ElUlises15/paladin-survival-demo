# Paladin Survival — demo web (build móvil)

Demo jugable de **Paladin Survival** (roguelite de mazmorras para Android). Jugala en el celu en horizontal:
https://elulises15.github.io/paladin-survival-demo/

- Joystick flotante a la izquierda, atacar/habilidad/esquivar/cambiar arma a la derecha, apuntado automático.
- **DEMO:** los anuncios y las compras están **simulados** (no hay anuncios reales ni cobros).
- Política de privacidad: https://elulises15.github.io/paladin-survival-demo/privacy/
- Modo clásico: `horda.html`. Panel de depuración: agregar `?debug` a la URL.

El código fuente es privado.
